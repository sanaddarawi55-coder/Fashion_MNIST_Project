
# Fashion-MNIST Image Classification

## Project Description
This project focuses on classifying clothing images using deep learning and PyTorch. We use the Fashion-MNIST dataset, which contains 70,000 grayscale images divided into 10 different clothing categories.

## Project Objectives
- Build a simple linear classifier.
- Compare different neural network models.
- Measure classification accuracy.
- Compare training time and model complexity.

## Dataset
Fashion-MNIST:
- 60,000 training images.
- 10,000 testing images.
- 10 different classes.
- Image size: 28 x 28 pixels.

## Technologies Used
- Python
- PyTorch
- Torchvision
- NumPy
- Google Colab

## Phase 1 Results
A simple linear classifier was trained for 5 epochs.

Validation Accuracy: 81.43%
